# Family Care Pharmacy

Repository for **Family Care Pharmacy** software and related assets.

## Status

Family Care Pharmacy marketing site — React + Vite, Weatherhaven-inspired layout with hero image, services slideshow, community map, news, and FAQ.

## About

Family Care Pharmacy tools and services live here. Use this repo for:

- Pharmacy operations and workflow software
- Internal tools for staff
- Configuration, scripts, and deployment assets (as they are added)

## Getting started

### Prerequisites

Install the tools required by whatever stack this project uses (for example Node.js, Python, or .NET). Update this section once the first application is committed.

### Clone

```bash
git clone https://github.com/acridge3-369/familycarepharm.git
cd familycarepharm
```

### Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).
